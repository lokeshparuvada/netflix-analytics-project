# Netflix Analytics Project

## Overview
This project analyzes Netflix dataset using Python, SQL, and Machine Learning.

## Features
- Data Cleaning
- Data Visualization
- SQL Database Integration
- Movie and TV Show Analysis
- Prediction using Machine Learning

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- SQLite
- Scikit-learn

## Project Structure

```text
PROJECT__/
│
├── Data/
├── database/
├── src/
├── main.py
├── requirements.txt
└── README.md
```

## How to Run

```bash
pip install -r requirements.txt
python main.py
```
